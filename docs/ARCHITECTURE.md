## Data Flow Invariants

1. No external network calls in default offline mode.
2. Every state delta must pass constitutional safety checks before execution.
3. Every committed state must have a verifiable Merkle root recorded in BlockSwarm.
4. Rendering is a pure projection of verified state; no authoritative mutation occurs in the Godot layer.

## Integration Points

- SEEM ↔ CFT: Symbolic intent vector → field equation parameters
- CFT ↔ Security: Proposed mutation set → rule evaluation
- Security ↔ Blockchain: Approved delta → IFP audit + Merkle commit
- Blockchain ↔ GDExtension: Confirmed state root → visual delta
